
Ce répertoire contient la partie RMI réalisée dans le cadre de la SAÉ "Du code au déploiement". Il ne contient que des fichiers Java afin de tester le mécanisme de RMI (Remote Method Invocation). Ce mécanisme permet à des objets Java s'exécutant sur une JVM d'invoquer des méthodes sur d'autres JVM.
